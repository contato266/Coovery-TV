# Coovery TV+

Hub de mídia open-source (baseado em ARVIO) com nome e logos personalizados da Coovery.

## Status

- Nome do app alterado para **Coovery**
- Ícones do launcher (celular) e banner da Android TV substituídos pelas logos da Coovery
- Package name ainda é `com.arvio.tv` (pode ser alterado se desejar)

## Como gerar o APK

```bash
./gradlew :app:assembleDebug
```

O APK sai em `app/build/outputs/apk/debug/`.

## Origem

Este repositório é uma personalização do projeto [ARVIO](https://github.com/ProdigyV21/ARVIO).
